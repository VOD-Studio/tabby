Tabby 是适用于 Linux 和 macOS 的中文 mihomo 终端控制台。它可以连接正在运行的内核，也可以安装并托管自己的 mihomo。

本手册以稳定版 **v0.3.1** 为准。`main` 上的未发布功能会在相关页面注明。截图中的端口、节点和订阅来自本地演示配置。

## 安装后从这里开始

先按系统完成[安装](./install/)。启动后可按 `?` 打开当前页面的帮助。

- 已有本机或远程 mihomo？准备好外部控制器的地址和密钥，然后[连接已有内核](./quick-start/connect/)。
- 想在终端里管理内核和订阅？按[托管 mihomo](./quick-start/managed/)启用托管模式。
