在 `config.toml` 提供 `[core]` 即可开启托管功能，`default = "core"` 让 Tabby 启动时选择它。也可以在 `P` 配置菜单中切换到它。首次接入见[托管快速开始](../../quick-start/managed/)。

## 内核从哪里来

Tabby 依次检查以下来源。

1. `[core].binary` 指定的内核。
2. Tabby 数据目录的 `core/bin/mihomo`。使用随包内核时，Tabby 会先把它复制到该目录。
3. 从 `PATH` 找到的 `mihomo`。
4. 找不到可用内核时，在界面里询问是否下载。

「设置 → 托管内核 → 内核」显示当前来源。安装在数据目录里的内核归 Tabby 管理；手动指定或来自 `PATH` 的版本由安装它的工具负责升级。

## 启停和升级

托管时 Linux 优先使用 systemd 用户单元，macOS 优先使用 launchd 用户域。检测不到相应进程管理器时，内核以独立进程运行。退出 TUI 后内核仍可运行，下一次选择托管配置会连接或启动内核。

- **停止**。在设置页选「停止内核」，按 `Enter`，再按 `y` 确认。
- **重启**。从设置页使用「重启内核」，连接可能短暂中断。
- **升级**。在托管区选择「升级内核」。确认版本后等待下载、检查和重启。需要使用 TUN 时，升级后按界面提示重新授权。

父目录受挂载限制、版本不兼容或新内核启动失败时，记录界面提示和 `core.log`。数据目录和日志路径见[配置参考](../../reference/configuration/#文件位置)。

## 备份和编辑

`core/profiles/` 保存已导入的配置，`core/subscriptions.toml` 记录订阅，`core/settings.toml` 记录端口、DNS 等托管设置。`core/home/config.yaml` 由 Tabby 根据当前订阅与设置生成。要修改配置来源，请编辑原文件后重新更新订阅，或通过设置页修改覆盖项。

订阅地址、age 私钥和控制器密钥可能存在于数据目录中。备份时按含敏感信息的文件处理。
