## 系统要求

| 系统 | 架构 | 最低要求 |
| --- | --- | --- |
| Linux | x86_64、aarch64 | glibc 2.35 |
| macOS | Apple Silicon、Intel | macOS 12 |

用 `uname -m` 查看当前架构。终端至少需要 50 列 × 15 行，缩小窗口时布局会自动简化。

## 使用 GitHub 发布包

打开[下载页](../../download/)，下载对应架构的压缩包和同一版本的 `SHA256SUMS`，放在同一目录。文件名以 `-with-mihomo.tar.gz` 结尾的包附带内核，适合托管模式。普通包可连接已有内核，也可以在启用托管后下载内核。

<Tabs>
<TabItem label="Linux">

在下载目录运行下列命令。例子使用 x86_64 的带内核发布包，其他变体替换 `archive` 的值。

```sh
archive='tabby-0.4.0-x86_64-unknown-linux-gnu-with-mihomo.tar.gz'
awk -v archive="$archive" '$2 == archive' SHA256SUMS | sha256sum --check -
```

校验输出应包含所选文件和 `OK`。

</TabItem>
<TabItem label="macOS">

在下载目录运行下列命令。例子使用 Apple Silicon 的带内核发布包，Intel Mac 选择文件名包含 `x86_64-apple-darwin` 的包。

```sh
archive='tabby-0.4.0-aarch64-apple-darwin-with-mihomo.tar.gz'
awk -v archive="$archive" '$2 == archive' SHA256SUMS | shasum -a 256 --check -
```

校验输出应包含所选文件和 `OK`。从浏览器下载的压缩包如果带有 `com.apple.quarantine` 属性，校验通过后、解压前可运行 `xattr -d com.apple.quarantine "$archive"`。

</TabItem>
</Tabs>

确认所选包校验通过后，用同一 `archive` 变量解压。

```sh
mkdir -p "$HOME/.local"
tar -xzf "$archive" -C "$HOME/.local" --strip-components=1
```

确认 `~/.local/bin` 在 `PATH` 里。使用带内核发布包时，保留解压得到的 `lib/tabby/mihomo` 与 `bin/tabby` 的目录关系，Tabby 才能找到随包内核。

```sh
tabby --version
```

如果出现 `command not found`，先用 `"$HOME/.local/bin/tabby" --version` 确认安装文件，再把 `$HOME/.local/bin` 加到 shell 的 `PATH`。

## 包管理器与源码

**Homebrew**

```sh
brew install vod-studio/tabby/tabby-mihomo
```

**Arch Linux**

使用仓库的 [PKGBUILD](https://github.com/VOD-Studio/tabby/blob/main/packaging/arch/PKGBUILD) 构建 `tabby-mihomo` 包。

```sh
git clone https://github.com/VOD-Studio/tabby.git
cd tabby/packaging/arch
makepkg -si
```

Arch 中的 Tabby 终端也使用 `/usr/bin/tabby`，这两个包存在文件冲突。

**源码**

使用当前稳定版 Rust，选择与本手册匹配的标签。

```sh
git clone --branch v0.4.0 https://github.com/VOD-Studio/tabby.git
cd tabby
cargo install --locked --path .
```

Homebrew、Arch 和源码安装均可直接连接已有内核。启用托管模式后，Tabby 会查找本机的 `mihomo`，找不到时会询问是否下载。
