在 `config.toml` 添加 `[core]` 后，可以运行 `tabby --profile core` 或按 `P` 选择「托管内核」。首次接入见[托管快速开始](../../quick-start/managed/)。

## 内核从哪里来

Tabby 依次检查以下来源。

1. `[core].binary` 指定的内核。若设置了这个路径，Tabby 会使用它，路径错误时会报错。
2. Tabby 数据目录的 `core/bin/mihomo`。使用随包内核时，Tabby 会先把它复制到该目录。
3. 从 `PATH` 找到的 `mihomo`。
4. 前几项均未提供内核时，Tabby 会查询可下载的版本并询问是否安装。

「设置 → 托管内核 → 内核」显示当前使用的内核路径。安装在数据目录里的内核由 Tabby 管理。手动指定或来自 `PATH` 的内核由原安装方式负责升级。

## 启停和升级

托管时 Linux 优先使用 systemd 用户单元，macOS 优先使用 launchd 用户域。检测不到相应进程管理器时，内核以独立进程运行。退出 TUI 后内核仍可运行，下一次选择托管配置会连接或启动内核。

- **停止**。在设置页选「停止内核」，按 `Enter`，再按 `y` 确认。
- **重新启动**。内核已停时，按 `r` 再次启动。运行中的内核可通过「设置 → 维护 → 重启内核」重启，连接可能短暂中断。
- **升级**。在托管区选择「升级内核」。发现新版本时按 `y` 确认，等待下载、校验和重启。需要使用 TUN 时，升级后按界面提示重新授权。

遇到启动错误时，先记下界面提示，再按进程管理方式查看[启动日志](../../troubleshooting/#去哪里看日志)。

## 备份和编辑

`core/profiles/` 保存已导入的配置，`core/subscriptions.toml` 记录订阅，`core/settings.toml` 记录端口、DNS 等托管设置。`core/home/config.yaml` 由 Tabby 根据当前订阅和设置生成。修改本地订阅时，编辑导入前的源文件，再到订阅页按 `u` 重新读取。端口、DNS 等覆盖项可在设置页修改。

订阅地址、age 私钥和控制器密钥可能存在于数据目录中。备份时按含敏感信息的文件处理。
