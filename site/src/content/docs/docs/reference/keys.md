---
title: 快捷键与鼠标
description: 查找全局快捷键、列表导航和过滤输入行为。
---

按 `?` 查看全局和当前页面的快捷键。大小写有不同含义，例如代理页的 `t` 和 `T`。

| 按键 | 操作 |
| --- | --- |
| `1`–`8` | 概览、代理、Providers、规则、连接、日志、设置、订阅 |
| `Tab` / `Shift+Tab` | 切换到下一页 / 上一页 |
| `j` / `k`、`↓` / `↑` | 移动列表选中项 |
| `gg` / `G` | 跳到列表顶部 / 底部 |
| `Ctrl+d` / `Ctrl+u` | 常见列表向下 / 向上翻半页 |
| `Enter` / `/` | 按上下文确认或查看详情 / 进入筛选 |
| `r` / `m` | 刷新或重试 / 切换代理模式 |
| `P` / `C` | 切换控制器 / 主题 |
| `?` / `Esc` | 打开帮助 / 关闭当前弹窗 |
| `q` / `Ctrl+C` | 退出 |

输入筛选条件时，字母键输入文字。按 `Enter` 接受条件，`Esc` 清除，`Ctrl+C` 仍可退出。批量操作可能只作用于过滤后可见的条目。

鼠标支持单击选择、双击确认、滚轮滚动和拖动滚动条。在终端想用鼠标选择文字时，可按终端的修饰键，或用 `mouse = false` 关闭 Tabby 的鼠标接管。
