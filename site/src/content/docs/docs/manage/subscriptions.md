## 支持的来源和格式

可以导入 HTTP/HTTPS URL 或本地文件。支持完整的 Clash YAML、纯文本或整体 Base64 编码的分享链接列表，以及 age 加密的订阅。

- **完整 YAML**。代理组、规则和 Providers 来自订阅，运行时由 Tabby 写入托管所需的控制器与端口设置。
- **分享链接列表**。Tabby 会为链接列表生成一个代理 Provider 和「节点选择」组。应用后可在代理页核对节点。
- **age 加密**。仅支持 X25519 私钥。导入时按提示输入，之后可在订阅页用 `K` 更换。Tabby 为更新保存私钥，`subscriptions.toml` 内的私钥为明文，文件权限为 `0600`。

## 选择下载路线

选中「设置 → 托管内核 → 订阅下载」，按 `Enter` 从默认的直连切换到经托管内核。再按一次可输入自定义代理地址，提交后启用。自定义地址支持 `http`、`https`、`socks5` 和 `socks5h`。在自定义代理状态下再按 `Enter` 可回到直连。

经托管内核下载依赖当前可用的 Mixed 端口。若订阅地址通过这条路线无法访问，可改用直连或自定义代理，然后按 `u` 重新下载。本地文件直接从原路径读取。

## 更新与恢复

URL 订阅默认每 24 小时自动更新一次。Tabby 保持打开且选中托管内核时会检查到期的订阅。按 `t` 切换自动更新，按 `i` 输入 1–8760 之间的整数小时。本地订阅用 `u` 手动读取。

更新使用中的订阅会尝试重新加载内核。下载或校验失败时，已有内容会保留。先核对订阅地址、下载路线和 age 私钥，再重新更新。用 `U` 批量更新时，先清除无意留下的过滤条件，或特意过滤到本次更新范围。

操作键表见[订阅页](../../use/subscriptions/)。
